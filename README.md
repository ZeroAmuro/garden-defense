# 🌻 花园保卫战 (Garden Defense)

一个纯 HTML + Canvas 的原创塔防小游戏，玩法参考经典的"植物大战僵尸"类型：在草坪上种植植物，阻挡一波波来袭的果冻怪物，守住你的花园。

## 玩法

- **收集阳光**：点击天空掉落、或向阳花产出的阳光，获得能量。
- **种植植物**：点击顶部卡片选中植物，再点击草坪格子种植（需要足够能量）。
- **坚持 10 波**：守住花园血量不被怪物耗尽即为胜利。

| 植物 | 费用 | 作用 |
|------|------|------|
| 向阳花 | 50 | 定期产出阳光 |
| 豌豆枪手 | 100 | 发射子弹攻击怪物 |
| 冰霜花 | 175 | 发射可减速的冰弹 |
| 铁壁果 | 50 | 高血量肉盾，拖延怪物 |
| 爆浆果 | 150 | 延迟后爆炸，大范围伤害 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 操作

- 鼠标点击：选卡 / 种植 / 收集阳光
- 右键：取消选择
- 铲子：铲除已种植物
